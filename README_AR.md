# وفرة — حزمة تحديث Build 3.1

ارفع `lib/main.dart` إلى `lib/main.dart`، و`pubspec.yaml` إلى جذر المستودع، وكل صور `assets` إلى مجلد `assets` على GitHub.

المُنفَّذ: تحية سعودية عشوائية عند كل تشغيل جديد، شاشة ترحيب واحدة بالجملة المعتمدة وزرين، الأيقونة المعتمدة، إصلاح التحقق من إدخال هدف الادخار، الحفاظ على مفاتيح SharedPreferences القديمة، تحليل الحوالات السعودية الحالي، وصورة رمز الريال.

تنبيه: زرا البداية وتسجيل الدخول يصلان إلى شاشة الدخول التجريبية الحالية، ولا يوجد تسجيل دخول حقيقي متصل بخادم. الميزات الاثنتا عشرة المقترحة سابقًا ليست كلها مطبّقة بعد. لم يتم تشغيل Flutter build في هذه البيئة؛ اختبر GitHub Actions قبل اعتماد النسخة.
